# wab_ext
 wab_ext is a WhatsApp bulk messenger extension with accessibility features.

 I made this mainly for blind users so they can send WhatsApp messages without saving phone numbers.

 The extension finds the required DOM elements in WhatsApp Web, opens the chat using the phone number, enters the message, and clicks the Send button automatically.

 A 20-second delay is added between each message to avoid sending messages too quickly.

 extension can be opened by using alt+w
